# Archived records

Records in archived_results/ preserve existing measurements, not new experiments.
Machine-specific absolute paths have been replaced by descriptive relative identifiers.
external_inputs/, external_weights/ and archived_results/ values in historical records are
artifact identifiers, not a claim that every original input is bundled. Use current CLI paths.
Raw primary images are external; model paths are mapped in model_manifest.csv.
Numerical fields and class names were not recomputed.
